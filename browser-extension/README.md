# 77 Pet 网页桌宠

Chrome / Edge 网页插件。桌宠浮在当前网页上，可拖动、点击回应、随机走动和碎碎念，网页其他区域不受影响。

## 开发

在仓库根目录执行：

```bash
npm run web:build
```

生成目录：

```text
browser-extension/dist/
```

## 安装

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 打开「开发者模式」。
3. 选择「加载已解压的扩展程序」。
4. 选择 `browser-extension/dist`。

普通网页会自动出现桌宠。内部页面、扩展商店和部分受保护页面无法注入，这是浏览器限制。

## 使用

- 单击宠物：随机回应。
- 拖动宠物：移动位置；快速甩动会带着惯性飞出去。
- 右键或长按：打开菜单，可切换宠物、使用「动作」分类直接点播动画，或让宠物回右下角。
- 点头顶气泡：收起当前这句话。
- 点浏览器工具栏里的 77 Pet 图标：切换宠物、调整大小和透明度、开关碎碎念。

## 边界

- 宠物只在网页内容上活动，不会盖住其他软件。
- 活动范围和点击区按宠物实际可见像素计算，动画四周的透明留白不会占位置。宠物身体可以贴到网页四边。
- `frame-bounds.json` 记录每种宠物待机画面里角色身体所占的比例。新增或替换宠物素材后，需要按待机动画的可见区域更新这个文件。
- 宠物素材随插件打包，不依赖电脑端程序。
